# source/

Simulated training and test datasets are written here. They are not distributed in
this repository: the evaluation subsets are on Figshare
(https://doi.org/10.6084/m9.figshare.33496762), and the training set (a 120 GB waveform
bank) is regenerated with the scripts in `forward/` (see "Train Data Generation" in the
top-level README).
