# TH-DeepSIF

Transformer-based deep learning source imaging framework for high-frequency
oscillations.

This repository will host the code accompanying:

> Rong J, Cai Z, Gonsisko C, Joseph B, Worrell GA, He B.
> **Transformer-based EEG Source Imaging Localizes Pathological High-Frequency
> Oscillations in Focal Epilepsy.** *Brain Communications*, 2026.

## Code release

**The source code will be released here shortly.** It will include:

- the neural mass model simulation and forward modelling pipeline
- the TH-DeepSIF architecture and training code
- evaluation on simulated and clinical data, and the sLORETA benchmark
- the statistical and figure-generation scripts underlying the reported results
- the head model, lead fields and trained model weights
- a de-identified example recording, so the pipeline can be run end to end

The simulated datasets used for the reported evaluations will be deposited
separately and linked from here.
